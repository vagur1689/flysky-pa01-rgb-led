# 富斯 FlySky PA01 遥控器 RGB 灯效控制脚本

[下载脚本压缩包](https://github.com/vagur1689/flysky-pa01-rgb-led/archive/refs/heads/main.zip) · [English](README.md)

专为 **富斯 FlySky ProArt PA01**（`320×240` 彩屏，EdgeTX 2.11+）定制的可视化 **RGB 色盘调色工具 + 锁定/解锁智能灯效引擎**。支持通过屏幕上的 **RGB 圆形色盘**和**可视化滑动条**独立设置 **开机电源键灯光** 与 **机身左右两侧灯条**，并跟随 `SA` 解锁开关自动切换灯效。

## 功能概览

| 控制部位 | 锁定状态（`SA` 弹起） | 解锁状态（`SA` 按下） | 可调参数（Tools 图形界面） |
| --- | --- | --- | --- |
| **开机电源键灯**（2 颗 RGB 灯珠） | 固定常亮 / 呼吸渐变 / 跟随状态 / 系统默认 | 固定常亮 / 呼吸渐变 / 跟随状态 / 系统默认 | 25 色 RGB 色盘、强度滑动条（`0–100%`）、4 种模式 |
| **左右两侧灯条**（每侧 2 颗 RGB 灯珠） | 固定常亮（RGB 色盘选色 + 独立强度滑动条） | 左右独立配色 + 5 种动态灯效组合 | 左右独立 25 色 RGB 色盘、强度滑动条（`0–100%`）、速度滑动条（`1–10`）、左右方向切换 |

### 解锁状态 5 种灯效组合

1. **`固定双色`**：左灯条常亮左色 A，右灯条常亮右色 B（选相同颜色即为全机同色）。
2. **`同步渐变`**：左色 A、右色 B 同步明暗呼吸。
3. **`反向渐变`**：左亮右暗 ⇄ 右亮左暗交替呼吸。
4. **`双色循环`**：颜色在左色 A ⇄ 右色 B 之间带相位差平滑流动循环。
5. **`全色循环`**：左右灯条带相位差沿 `360°` RGB 色盘自动流光循环。

## 安装与使用（3 步生效）

1. **复制文件到遥控器 TF 卡**：
   - `/SCRIPTS/TOOLS/pa01led.lua`：前台可视化 RGB 色盘与滑块配置工具。
   - `/SCRIPTS/RGBLED/pa01led.lua`：后台常驻灯效驱动脚本。
2. **启用后台灯效脚本**：
   - 长按 **SYS 键**进入系统设置，翻页到 **`全局功能 (Global Functions)`**。
   - 找到原本运行 `FS_brth` 的 **`RGB LED 灯`** 条目，将脚本文件改为 **`pa01led`**，开关保持 **`ON`**。
3. **打开可视化色盘调色**：
   - 短按 **SYS 键**进入 **`工具 (Tools)`** 菜单，点击 **`pa01led`**。
   - **滚动滚轮**上下选择项目，**短按滚轮**进入调节（此时色盘外框或滑块圆点变黄，转动滚轮即可沿右侧 RGB 色盘选色或拉动滑条，真机灯光实时同步变化），再次**短按滚轮**完成该项调节。
   - 按 **`RTN`（退出键）**或点击底部的 **`[保存设置]`**，配置自动写入 `/SCRIPTS/RGBLED/pa01led.cfg` 并经过回读校验，无需重启遥控器即可生效。
